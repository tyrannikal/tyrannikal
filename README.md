## Howdy

I'm returning to software engineering after many years away. C/C++ and Java were my home before, and I'd like to respark that. However, since I'm a noob again anyway I might as well try something new too, so I'm learning Python, Rust, and Go will work its way in there. Also trying to build the habit and experience with more fully implementing tiger style (based on NASA power-of-ten rules for safety critical code). Losing recursion makes me kinda sad, but the benefits of foregoing it regretfully appear to outweigh its use. Shame but in the end the methodology has so far shown to be effective in producing more reliable code, with less debug time and a better night's sleep 💤.
